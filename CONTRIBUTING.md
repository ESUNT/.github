# Contributing to ESUNT

Thank you for your interest in contributing to **ESUNT - Secure Communication, Reinforced!**

ESUNT is an independent, serverless over-encryption technology. Our immediate development priority is the Android minimum viable product (MVP), followed by testing, independent security evaluation, and broader integration work.

## How you can contribute

We welcome interest in:

- Android and cross-platform application development
- Applied cryptography and security research
- Software architecture and communication-platform integration
- User interface and experience design
- Testing, documentation, and quality assurance

## Getting started

1. Read the public project information at [esunt.org](https://www.esunt.org/).
2. Review the README and contribution instructions in the specific ESUNT repository you are interested in.
3. When Issues or Discussions are available, check existing topics before proposing a new one.
4. Discuss substantial changes with the maintainers before starting implementation work.
5. For a repository accepting pull requests, follow its documented testing, review, and licensing requirements.

If no relevant public repository or contribution process is available yet, contact [contact@esunt.com](mailto:contact@esunt.com) to introduce your skills and interests.

## Public contributions and confidential material

ESUNT has intellectual property filings, and some technical documentation is confidential. **Do not publish confidential specifications, unpublished implementation details, credentials, private communications, or third-party proprietary material** in issues, discussions, or pull requests.

Public access to documentation does not imply that every ESUNT component is open source. Source-code release scope, licenses, and any additional contribution terms will be specified in the relevant repositories when they are ready.

If you are unsure whether information is intended for public disclosure, contact the ESUNT team before posting it.

## Security reports

Do not disclose suspected vulnerabilities in public issues. Follow our [Security Policy](https://github.com/ESUNT/.github/blob/main/SECURITY.md).
