
# ESUNT

**Secure Communication, Reinforced!**

ESUNT is an independent, serverless over-encryption technology designed to protect digital communications beyond the security provided by existing messaging platforms.

By encrypting content before it reaches the communication application, ESUNT gives users independent control over an additional layer of cryptographic protection.

The technology supports two complementary approaches:

- **Independent encryption** alongside compatible messaging and communication applications.
- **Standalone secure communication** through a dedicated ESUNT messenger architecture.

## About the Project

ESUNT was invented by **Dr. Florian Radut**, a medical doctor and software architect with almost 40 years of computer experience.

The project is built around an original cryptographic architecture, supported by technical documentation, intellectual property filings, and a growing team of developers, designers, and collaborators.

## Development

Development objectives include:
